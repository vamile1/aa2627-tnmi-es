# TNMI

Esercitazioni accademiche di programmazione creativa con [p5.js](https://p5js.org/) (versione 2).

Questo è un **lavoro accademico**: gli sketch sono esercizi svolti per un corso, non progetti professionali.

Il codice è stato realizzato con l'assistenza di un **agente AI** (Claude Code), lavorando in Visual Studio Code. Come richiesto dalle consegne, il codice non è stato scritto da zero a mano: è nato dal dialogo con l'agente, è stato verificato passo per passo nel browser, poi letto e modificato direttamente.
